📚 Test Mate

Test Mate is a simple student-focused web app designed to help students understand their academic performance and plan their study time more effectively.

Instead of just showing grades, Test Mate analyzes your subjects, identifies areas that need more attention, and helps you decide how to spend your available study time.

🚀 Live Demo

👉 "Open Test Mate" (https://test-mate-one.vercel.app/)

✨ Features

- 📊 Grade Analysis — Enter your subjects and grades to analyze your academic performance.
- 💪 Strength & Weakness Detection — Identify subjects you're doing well in and subjects that need more attention.
- 📈 Average Performance — Get an overview of your overall academic performance.
- 📚 Study Planning — Enter your available study hours and get a study plan based on your performance.
- 💾 Offline Support — Test Mate is built as a Progressive Web App (PWA) and can continue working even without an internet connection.
- 📱 Responsive Design — Designed to work across different screen sizes and devices.

🛠️ Built With

- HTML — Structure
- CSS — Styling and responsive design
- JavaScript — Application logic and analysis
- PWA Technologies — Offline functionality and installability
- Vercel — Deployment

🎯 Why I Built It

Test Mate was created as a student-focused project to make academic performance easier to understand.

The idea is simple: your grades shouldn't just tell you how you performed — they should help you decide what to do next.
